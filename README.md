# TARO project website

TActile Understanding and History-Guided Reasoning for Online Failure Recovery.

Anonymous project website built with static HTML, CSS, and JavaScript.

## GitHub Pages

Set Settings → Pages → Build and deployment → Source to **Deploy from a branch**. Select **main** and **/ (root)**. The repository root contains index.html and .nojekyll; no build step is required.

## Content

- 14 autonomous TARO demonstrations with condition selection.
- 5 no-tactile and 2 no-motion-history ablation examples.
- Method and quantitative results. The paper PDF is not included in this public release.

All assets use relative URLs for GitHub Pages project sites. Edited playback speeds follow the labels in the videos.
